# Learn Article Writer — Scoring Rubric

Score each article 0-100 across these dimensions:

## SEO Quality (20 points)
- 20: Primary keyword in title, H1, meta, first 100 words, 2+ H2s. Secondary keywords in H3s. Perfect meta description. Clean URL slug. Canonical set. All OG/Twitter tags
- 15: Most SEO elements present, minor gaps (e.g., keyword missing from one H2)
- 10: Basic meta tags present but keyword optimization weak
- 5: Missing critical SEO elements
- 0: No SEO optimization

## GEO Optimization (20 points)
- 20: Definitive statements throughout. Entity-rich (names tools, versions, companies). 3+ citation-ready paragraphs. FAQPage schema with 3-5 real questions. HowTo schema if tutorial. First-party experience signals. Statistics/specifics cited
- 15: Good GEO with minor gaps (e.g., some hedging language, FAQ present but only 2 questions)
- 10: FAQ section present, some structured data, but content reads generic
- 5: Minimal GEO optimization — reads like any AI could have written it
- 0: No GEO signals, no schema beyond basic Article

## Content Depth & Authority (20 points)
- 20: Teaches something real. Includes code, examples, tables, specifics. First-party experience from Acrid's actual stack. Reader leaves knowing how to do the thing. No filler paragraphs
- 15: Good depth with minor filler or missing examples
- 10: Surface-level — covers the topic but doesn't go deep enough to be the definitive resource
- 5: Thin content, mostly definitions and generalities
- 0: Fluff or inaccurate

## Conversion & Marketing (20 points)
- 20: Natural product CTA that solves a problem just discussed. 2-3 CTA touchpoints. Affiliate links woven contextually. Internal links create a content funnel. Plausible events on CTAs
- 15: CTA present and relevant, affiliate links included, but placement feels slightly forced
- 10: CTA exists but generic ("check out our products"). Minimal affiliate integration
- 5: Product mention present but no real conversion path
- 0: No marketing integration

## Technical & Structure (20 points)
- 20: Valid HTML. All schema markup correct. Template fully filled. No placeholders. Responsive. Navigation/footer match site. Images optimized. Passes validator. Clean heading hierarchy
- 15: Minor technical issues (missing one schema, slight HTML issues)
- 10: Multiple technical problems but page renders correctly
- 5: Significant structural issues
- 0: Broken HTML, missing critical elements

---

## Scoring Bands
- **90-100:** Ship it. Exceptional — will rank and convert
- **80-89:** Ship it. Strong — will compete well
- **70-79:** Ship with minor fixes — good foundation, needs polish
- **60-69:** Needs revision — won't rank or convert as-is
- **Below 60:** Rewrite — fundamental issues

## Quick Self-Check (run before scoring)
- [ ] Would I click this in search results? (title + meta description)
- [ ] Does the first paragraph actually answer the query?
- [ ] Could an LLM extract a useful answer from each section?
- [ ] Is there a clear path from reading to buying?
- [ ] Does this sound like Acrid or like generic AI?
- [ ] Would this be the best result for this keyword if Google ranked it?
